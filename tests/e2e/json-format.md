# JSON 格式化纵切验收

公共约定见 [测试计划](../../docs/testing-plan.md)。用户已确认该工具范围及先测试、提交测试后实现的顺序。

- 匿名、本地生产构建；仅编辑页面内存输入/配置、运行、取消，不写持久化或外部服务。每个场景使用独立 context，结束关闭。
- E-01：默认缩进 2；0/4/8 缩进、Unicode/数组/null 固定输出；HTML 字符串不执行；真实同 origin Worker，不发送非 GET 或跨 origin 请求。非法和空 JSON 仅显示友好说明，不显示 `INVALID_INPUT` 或原始输入、无旧输出，修正后可运行。
- E-02：在主线程同一任务中点击运行后取消，保证 Worker 消息事件尚未投递，避免用大数据或网络延迟制造竞态；必须显示已取消、无旧输出，再次运行返回新输入结果。单元层另验证硬终止与迟到响应隔离。
- E-09：375px 下从缩进控件 Tab 到运行按钮，Enter 运行得到固定结果，页面无横向溢出。
- UI-02/03：组件层只替换浏览器 Worker 平台，验证禁用重复运行/编辑、输出与耗时、配置、错误恢复、编辑清除旧结果及卸载释放。

首次实现后在同一独立会话核实定位器：输入并运行合成 JSON 得到缩进结果；非法 `{` 当时显示 `INVALID_INPUT` 且清除输出；修正后使用 4 空格再次运行；同任务取消显示已取消；375px 下 Tab/Enter 运行成功，scrollWidth=375。已检查桌面与窄屏实际截图，探测会话已关闭。正式生产构建结果和环境限制见 [验证记录](../../docs/verification/json-format.md)。本次友好错误调整后重新探测并复跑，已不再显示错误码，见[补充验证](../../docs/verification/i18n.md#语言菜单与友好错误补充)。
