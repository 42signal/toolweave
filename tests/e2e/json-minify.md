# JSON 压缩与工具切换

范围：已确认下一切片，只增加 `json.minify` 和两个内置工具的切换，复用 JSON 原生语义、本地 Worker、取消与英中界面；不增加动态插件、通用 Schema 表单、持久化或工作流。公共规范见[测试计划](../../docs/testing-plan.md)。

匿名本地页面，仅编辑合成文本和当前页面语言、运行/取消；不上传、不持久化；每个测试使用独立 context，结束关闭。压缩配置仅空对象 `{}`，不接受 `indent`；空或非法 JSON 显示友好错误。切换保留输入、清除输出/错误/耗时，恢复待运行；运行中禁止切换，语言仍可切换。

## 场景 MIN-E01：双语压缩与恢复

入口 `/`，默认格式化。en-US / zh-CN 分别在 375px 执行：

- E1：显示 2 个工具，选择 JSON Minifier / JSON 压缩后标题及选中状态一致，无缩进配置。
- E2：真实同 origin Worker 压缩固定对象/Unicode 嵌套、数组、标量及 HTML 字符串；只去 JSON 结构空白，不改变字符串内空格，不把文本当 HTML。
- E3：非法和空输入显示友好错误，无错误码/原始输入、无旧输出；修正后重试成功。
- E4：无 page error、跨 origin 或非 GET 请求；375px 不横向溢出。

## 场景 MIN-E02：切换状态与双语

- E1：格式化成功后切到压缩，输入保留，输出和已完成耗时清空；压缩成功后切回亦清空。
- E2：压缩输出后切中文，仍选中压缩且保留输入/输出；切回格式化仅清输出。
- E3：键盘可聚焦工具按钮并按 Enter 选择，再聚焦运行按钮并按 Enter 执行。新增工具后 Tab 会依次经过其余工具按钮，不再假设压缩按钮的下一个焦点是运行；从缩进 Tab 到运行仍由 E-09 验证。

## 场景 MIN-E03：执行期间禁切换

- E1：真实运行的同一主线程任务中检查两个工具按钮禁用；尝试点击不能切换，取消后按钮恢复且显示已取消。
- E2：取消后可切格式化，再运行返回格式化结果，不混用压缩旧结果。

实现映射：`json-minify.spec.ts` 对应以上场景。`src/tools/execute-tool.test.ts` 复用 BT-01 脱敏错误，覆盖空配置约束与 CT-02 工具分发；`src/ToolWorkspace.test.tsx` 复用 UI-02 覆盖切换和执行状态。成功转换的固定向量留在 E2E，不为 JSON 标准库本身增加单元测试。

探测：agent-browser 0.43.0 / Chrome 157.0.8103.78 安装检查成功，独立会话访问 `http://127.0.0.1:5173/`，输入 JSON、选 4 空格、运行得到格式化结果；快照只有 1 个工具，没有工具切换。证据 `test-results/json-minify/probe/before.txt`。复用已核实的 Input/Output/Indent/Run 与中文定位器；新增 JSON Minifier / JSON 压缩按钮在实现后再核实，不以其当前缺失改变预期。

实现后同一会话已核实工具按钮、选中状态及双语标题：格式化 Unicode JSON 后切压缩，输入保留/输出清空；运行压缩得到固定无空白输出且字符串内双空格保留；改英文保留选择和结果。非法输入显示英文友好说明，切中文重新翻译，切回格式化保留输入并移除错误。375px scrollWidth=375，页面 errors 为空；已查看桌面/窄屏截图，会话已关闭。正式测试还覆盖同任务运行禁用/取消及键盘，结果见[验证记录](../../docs/verification/json-minify.md)。
