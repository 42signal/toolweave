# Cron 解析与组合

用户已授权首版与自定义编辑器/六段补充实现及测试；只操作本地合成输入，不持久化或外联。验证边界为公开 `executeTool`、真实 App 和生产 Worker，不单测第三方解析器。测试流程遵循 `docs/testing-plan.md`。

- **CRON-PARSE / CRON-SECONDS**：五/六段与配置边界；月份/星期名称偏移；六段秒范围 0–59、固定时钟下每十秒的精确 UTC 向量；日期/星期采用 OR 且不丢秒；非法七段/Quartz 拒绝，合法但无匹配日期为空列表。
- **CRON-UI / CRON-EDITOR**：唯一非 input 的纯文本自定义编辑器，保留未完成原文；光标/选区和字段名按钮控制高亮与说明 list；Tab / Shift+Tab 选择邻字段且首尾允许离开，Enter 不换行；整段/部分粘贴、非法字符与 HTML 整次拒绝、不破坏原选区，组合输入提交后同样校验；月/星期缩写允许部分编辑，删除放行；五/六段识别与切换、预设/Random 保持段数；Copy 原文/友好失败、编辑后复位；编辑/卸载取消旧 Worker，语言切换重算。
- **CRON-E01**：英中、375px，输入 `*/5 9-17 * * 1-5` 后自动预览；观察真实同源 Worker，描述含五分钟/工作日含义，五个后续时间严格递增且有时区；修改小时与清空字段再恢复同步；预设可恢复非法输入；语言切换和键盘可操作，页面无错误、无外联、无水平溢出。
- **CRON-E02**：UTC 和 Asia/Shanghai 各一条本地午夜向量；用浏览器 Date 独立计算明天本地午夜的 UTC 值，断言真实 Worker 后续首项严格相同；覆盖其余预设。E2E 不替换时钟、Worker 或解析库，Unit 的每五分钟固定时钟向量负责时间快照精确值。
- **CRON-E03**：英中、375px，自定义 contenteditable 中粘贴 `*/10 * * * * *`，自动识别六段；真实 Worker 描述每十秒、五个后续 ISO 间隔均为 10000ms，显示日期到秒；非法键入、中文插入和混合非法粘贴不改变表达式或选区，逐字输入 jul / WED 可得到有效说明；选择秒输入 60 报错，再改为 */15 恢复；Copy 真实原文、预设/Random 保持六段，切五段再切六段，页面不溢出。

本轮已授权交互补充：CRON-UI 验证光标/字段焦点联动范围和语法提示、Copy 原文/友好失败/编辑后复位、Random 固定随机源对应合法样例；UI-HOST 用可控时钟验证 150ms 防抖、取消/卸载及迟到响应。UI-REG 验证独立面板回退与整页互斥，普通工具与 Diff 复用现有用例。

CRON-E01 继续覆盖双语 375px：键盘移动光标到分钟提示步长，选中小时并输入更新表达式；Copy 成功（Chromium 授权剪贴板并读取真实内容）；Random 后真实 Worker 生成五次执行；清空小时保留原文并恢复；突出 Next；Tab / Shift+Tab 在邻字段切换，星期之后 Tab 到 Copy。WebKit 行首键采用 macOS `Meta+ArrowLeft`，Chromium 为 Home。CRON-E03 的 Chromium 使用授权真实剪贴板和 Meta+V；WebKit 分派携带真实 DataTransfer 的 paste 事件，属于粘贴处理验收，不声称已验证 WebKit 系统剪贴板读取。Worker 和解析器均不 mock。

支持五段或秒在首位的六段与 `* , - /`、月份/星期缩写和星期日 0/7；不支持七段、Quartz、昵称、命令列或调度执行。预览按当前时刻的一次快照计算，不作为后台计时器；DST 遵循 Croner 规则。
