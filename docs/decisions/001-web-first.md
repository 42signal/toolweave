# ADR-001：Web-first、local-first

状态：Accepted（Web 优先方向；具体行为与预算仍按协议 review）。

首版采用标准 Web PWA，内置工具、工作流和存储在浏览器本地完成；AI 是可选远程能力。理由是 PWA 已为明确需求，浏览器已有 Worker/IndexedDB/SW/WASM，静态部署可最快验证闭环；完整技术清单见[实施计划](../implementation-plan.md)。

暂不选 NSH-first/Tauri-first：先做桌面宿主会增加打包和跨平台验证，不能代替 PWA。暂不选后端-first：当前本地闭环不需要账号或服务端存储。工具协议和执行边界独立于 UI，保留后续复用空间。

代价：离线依赖首次预缓存成功；IndexedDB 无跨设备同步承诺；浏览器不提供任意系统命令。AI 工具须先证明沙箱隔离与可靠终止，否则暂停。

复审条件：真实文件/系统集成、全局快捷键/托盘、核心工具超出浏览器边界，或出现云同步/社区服务需求；桌面方向优先评估 NSH。
