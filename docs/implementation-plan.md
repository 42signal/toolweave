## 1. MVP 范围

产品闭环：**本地工具 → 线性串联 → 保存工作流 → 保存为工具 → AI 辅助串联和增加工具**。

| 必做       | 边界                                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| 内置工具   | 结构化 JSON/YAML 格式化/压缩、Base64 编码/解码、URL 编码/解码、JWT 解码、UUID、Unix 时间转换、URL ↔ JSON、Diff、Cron，共 13 个 |
| 工具串联   | `string → string`、单输入/输出、顺序执行、列表编辑、中间结果、失败停止、取消                                             |
| 复用与存储 | 保存/加载/删除工作流；工作流快照成为工具，可再次串联；本地导入/导出                                                      |
| AI 串联    | 自然语言新建/修改/修复工作流；本地校验、预览、确认，不自动执行                                                           |
| AI 工具    | 生成源码和测试数据；沙箱运行、独立验收、确认后启用，仅保存在本地                                                         |
| PWA        | 安装、首次预缓存完成后离线冷启动、离线执行已安装工具/工作流、安全更新提示                                                |
| 主题       | 浅色、深色、跟随系统，语义 Token，刷新保持                                                                               |
| 界面语言   | 英文默认与兜底、简体中文，跟随浏览器首个支持语言，切换不丢运行状态                                                       |

**不做**：社区市场/发布、账号/云同步/协作、原生桌面端、任意第三方插件、多输入/输出、分支/循环/并行/条件节点、无限画布、网络和文件系统工具。

## 2. 技术与架构

| 领域      | 选择                                                            |
| --------- | --------------------------------------------------------------- |
| 应用      | Vite、React、TypeScript strict、pnpm                            |
| 状态/存储 | Zustand 管理临时状态；Dexie + IndexedDB 持久化                  |
| 校验      | Zod 校验外部数据；JSON Schema + Ajv 校验工具配置                |
| 执行      | 内置工具在 Web Worker；AI 工具候选为 QuickJS-WASM + 独立 Worker |
| PWA       | `vite-plugin-pwa` + Workbox                                     |
| 测试      | Vitest、Testing Library、fake-indexeddb、Playwright             |
| 国际化    | i18next + react-i18next；类型约束的静态英中词典                 |

```text
UI → 功能服务/状态 → 注册表/工作流引擎 → Worker
                 → 存储服务 → IndexedDB
                 → AI adapter → 用户配置的远程服务
```

- UI 不直接调用具体工具或读写数据库；协议与 UI 解耦。
- 持久化只保存 manifest、源码、配置和必要快照，不保存函数或 Worker；执行输入/结果默认只在内存。
- 外部数据在边界校验；AI 输出不可信，本地功能不依赖 AI 可用性。
- 默认不向 AI 发送输入样例，Key 默认仅内存，不进日志、备份或缓存。
- SW 只缓存允许的静态 HTML/JS/CSS/图标/字体/WASM，不缓存 AI API、Key、用户输入/结果或未知跨域请求。
- WASM 静态文件预缓存与运行时懒初始化分开；沙箱隔离或终止验证失败即暂停 AI 工具，不以宿主 `eval` 替代。
