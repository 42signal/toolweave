- `src/i18n/locale.ts` 按 navigator.languages 顺序匹配 en/zh 基础语言，忽略大小写，所有中文变体映射 zh-CN，无匹配/缺少语言信息回退 en。

- Worker 与执行服务只保留英文诊断，不加载翻译资源；UI 按原有稳定错误码显示本地化说明，语言切换可重新翻译既有错误，不显示任意底层异常文本。
